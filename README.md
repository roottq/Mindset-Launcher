# 🚀 Mindset Launcher

Легкий, быстрый и полностью бесплатный лаунчер для Minecraft. 
Никакой рекламы, навязанных серверов и скрытых платежей. Только чистая польза.

## ✨ Особенности
* 🎨 Современный минималистичный интерфейс.
* 📦 Менеджер модов: включай/выключай моды в один клик.
* 📸 Галерея скриншотов прямо в лаунчере.
* ⚡ Встроенная оптимизация (флаги Aikar) для устранения лагов.
* ☕ Автоскачивание нужной версии Java.
* 🌐 Быстрый вход на сервер (Auto-Join).
* 👤 Система профилей под разные сборки.

## 🛠 Установка и запуск
1. Установи Python 3.10+.
2. Скачай этот репозиторий.
3. В терминале выполни: `pip install -r requirements.txt`
4. Запусти: `python main.py`
5. Есть уже готовый файл main(ТОЛЬКО ДЛЯ LINUX!!!), на windows пока только через команды.
